# WearCompass

WearCompass is an elegant, high-precision magnetic compass and azimuth indicator for Wear OS.

## Features
- Magnetic north orientation compass dial with smooth pointer rotation\n- Digital azimuth angle in degrees\n- Pitch black UI with high contrast readability

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.

## Technical Details
- **Namespace**: `com.ajimsjames.wearcompass`
- **Version**: `2.1.0`
- **Target OS**: Wear OS (API 30+)
